# Summoners War game icons

Official game artwork mirrored from the SWARFARM public repository:
https://github.com/swarfarm/swarfarm/tree/d68ee42efa554238b6f38471e3a9e7b33031bf62/herders/static/herders/images

- `elements/*.png`: `images/elements/{water,fire,wind,light,dark}.png`
- `runes/rune1.png` through `runes/rune6.png`: original slot-specific rune stones, used beneath the set glyphs in shared PNGs.
- `runes/*.png`: `images/runes/<lowercase English set name>.png`

Set and element icons copied without graphical modification on 2026-10-22;
slot-specific rune stones added from the same upstream on 2026-10-27. Game artwork belongs to
Com2uS and its respective rights holders. These are game identifiers, not artwork
created by this project. Local files avoid remote image requests in the selectors
and make card exports independent of the icon CDN.
